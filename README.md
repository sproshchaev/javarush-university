# javarush-university

План разработки:

1. Проработка структуры проекта
```txt
   MorseApp -> service -> core 
   java
       \com.javarush.morse
               \config - этого нет (в нашем проекте)
               \core (common) - ядро, основная логика (азбука, алгоритм)
               \controller - этого нет
               \exception - исключения 
               \model (domain) - этого нет 
               \service  - слой сервисов, вспом. работа вокруг ядра  
               \repository - этого нет 
               \util - этого нет  
               MorseApp.java
          
```
